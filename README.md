# Fatigue Detector — Детектор усталости

## Установка

```bash
pip install opencv-python mediapipe pygame numpy
```

## Запуск

```bash
python fatigue_detector.py
```

При первом запуске программа автоматически скачает модель **face_landmarker.task** (~30 МБ).

## Управление

| Клавиша | Действие |
|---------|----------|
| `Q` / `ESC` | Выход |
| `S` | Сохранить скриншот |

## Алгоритм

| Метрика | Формула | Порог |
|---------|---------|-------|
| **EAR** (Eye Aspect Ratio) | (A+B) / 2C по 6 точкам глаза | < 0.20 → закрыты |
| **MAR** (Mouth Aspect Ratio) | вертикаль / горизонталь рта | > 0.55 → открыт |

- **Глаза закрыты > 4 сек** → звуковой сигнал (880 Гц)
- **Рот открыт > 5 сек** → звуковой сигнал (660 Гц)

## Настройка порогов

В начале файла `fatigue_detector.py`:

```python
EAR_THRESHOLD   = 0.20   # снизить если ложные тревоги
MAR_THRESHOLD   = 0.55   # повысить если рот «открыт» при разговоре
EYE_CLOSED_SEC  = 4.0    # время закрытых глаз до тревоги
MOUTH_OPEN_SEC  = 5.0    # время открытого рта до тревоги
```

## Требования

- Python 3.8+
- Веб-камера
- Интернет (только при первом запуске для загрузки модели)
